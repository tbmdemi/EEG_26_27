\section{Contributions}
\label{ch:contributions}

The work was divided into five roles with one owner each (Table~\ref{tab:contributions}); shared decisions were fixed in the analysis protocol and changed only with a logged reason. Each member recorded every delivered item, with links to the corresponding pull requests and commits, in a shared contribution log (\src{reports/contribution_log.md}). The table lists contributions to date. The percentages will be agreed by all members on the basis of this log at the end of the project and will add up to 100\%.
